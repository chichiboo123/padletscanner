# 📋 Padlet Scanner — 패들렛 스캐너

패들렛 계정의 모든 보드 데이터를 한눈에 분석하고 엑셀로 내보낼 수 있는 **순수 클라이언트 웹앱**입니다.

별도 서버 없이 브라우저에서만 동작하므로, 입력한 API 키는 외부로 저장되거나 전송되지 않습니다.

---

## ✨ 주요 기능

| 기능 | 설명 |
|------|------|
| 보드 목록 조회 | 패들렛 계정에 연결된 전체 보드를 한 번에 불러옵니다 |
| 게시글 · 댓글 수 분석 | Admin 권한 보드의 게시글 수 · 댓글 수를 자동 집계합니다 |
| 요약 통계 | 총 보드 수, 게시글 수, 댓글 수, 보드당 평균, 공개 보드 수, 최근 수정일을 카드로 표시합니다 |
| 엑셀 다운로드 | 현재 화면에 표시된 순서 그대로 `.xlsx` 파일로 내보냅니다 |
| 실시간 검색 | 보드 제목 · 설명을 실시간으로 검색 · 필터링합니다 |
| 그룹핑 | 연도별 / 키워드 자동 / 키워드 수동 / 묶음 없음 4가지 모드로 보드를 그룹화합니다 |
| 정렬 | 보드 제목, 생성일, 수정일, 게시글 수, 댓글 수 기준 오름차순 · 내림차순 정렬 |
| 데이터 캐시 | 마지막 조회 결과를 브라우저 로컬스토리지에 저장, 다음 방문 시 즉시 복원 |
| 동기화 | 캐시된 데이터를 최신 API 데이터와 비교해 변경 · 신규 보드를 하이라이트로 표시 |
| 조회 취소 | 조회 진행 중 언제든 취소 버튼으로 중단 가능 |

## 🚀 사용 방법

### 1. API 키 발급

1. [padlet.com](https://padlet.com) 로그인
2. **계정 설정 → 개발자 API** 메뉴로 이동
3. API 키 발급 (유료 구독 계정 필요)

### 2. 보드 조회

1. 발급받은 API 키를 입력란에 붙여넣기
2. **보드 목록 조회** 버튼 클릭 (또는 Enter 키)
3. 분석이 완료되면 요약 통계와 보드 목록이 표시됩니다

### 3. 결과 활용

- **엑셀 다운로드** 버튼으로 현재 화면의 데이터를 `.xlsx`로 저장
- 상단 검색창에서 보드 제목 · 설명으로 즉시 검색
- 묶음 드롭다운으로 연도별 · 키워드별 그룹화
- 컬럼 헤더 클릭으로 정렬 기준 변경

## 🔒 보안 및 개인정보

- 이 웹앱은 **별도 서버가 없는 순수 클라이언트 앱**입니다.
- 입력한 API 키는 **외부 서버에 저장되거나 전송되지 않으며**, 브라우저 메모리 및 로컬스토리지 내에서만 사용됩니다.
- API 키는 개인 패들렛 계정과 직결되는 중요 정보입니다. **타인에게 절대 공유하지 마세요.**
- 공용 컴퓨터 사용 후에는 **초기화** 버튼을 눌러 캐시를 삭제해 주세요.

---

## ⚙️ CORS 프록시 설정

패들렛 API는 브라우저에서 직접 호출 시 CORS 정책으로 차단될 수 있습니다.

- **CORS 프록시 우회 (Cloudflare Worker)** 옵션을 활성화(기본값)하면 Cloudflare Worker를 경유하여 CORS를 우회합니다.
- 로컬 환경 또는 GitHub Pages에서 실행할 경우 이 옵션을 켜두는 것을 권장합니다.
